# Module 5 预测结果评估改造报告

日期：2026-10-22

## 工作流

Module 5 现采用两栏布局：

- 左侧：评估配置与评价历史。
- 中央：五个固定纵向区域，不使用中央标签页，也不提供右侧独立栏。

中央顺序：

1. 预测详情（Forecast Details）
2. 预测对比（Prediction Comparison）
3. 误差分析（Error Analysis）
4. 预测时域分析（Forecast Horizon Analysis）
5. 评估概览（Evaluation Overview）

## 实验选择与兼容性

- 数据集只列出来自 Module 3 的单区域已构建数据集。
- 训练实验必须由用户手动勾选，不自动选择最近实验，也不自动加载批次。
- 列表按 EXP ID 独立展示；同一模型的多个训练记录不会合并。
- 后端再次校验数据集版本、区域、训练状态、L/H/S 和数据哈希。
- 不兼容实验会返回具体 EXP ID 和原因，不能进入有效排名。

## 测试范围与指标

- 默认使用数据集保存的完整测试集。
- 自定义范围必须位于测试集内，worker 会真实裁剪测试窗口。
- 预测值按目标时间戳对齐；同一实验、h 和目标时间的重复记录保留最早预测窗口。
- 整体指标使用全部有效测试窗口和 h=1 至 h=H 的全部预测。
- 每个 horizon step 单独计算 MAE、RMSE、sMAPE、R² 和有效样本数。
- 预测对比中的 h 选择器只改变当前展示，不改变 H、模型和评估结果。

## 历史记录

- 评价历史位于左侧配置下方。
- 每条历史提供“查看”和“删除记录”。
- 历史保存并恢复 EXP ID 清单、实验参数、训练完成时间、数据集版本、测试范围、显示步长和指标结果。
- 查看历史不会使用当前新配置覆盖已保存结果。
- 删除评价只删除评价预测、成员关系和任务记录，不删除数据集、训练实验或模型文件。

## 导出功能清理

已删除：

- 左侧和评价历史中的导出按钮。
- 图表、预测数据、误差、指标、排名和时域分析导出入口。
- 前端 `evaluationExport` 调用和通用下载地址函数。
- 后端 CSV 导出实现及依赖。

兼容旧链接时 `/api/evaluations/{id}/export` 明确返回 404，不再返回文件。
